# Курсограф

Настольный конвертер валют для лабораторной работы №3 по PSI. Использует официальный курс Национального банка Молдовы для MDL, EUR, USD, RON, UAH и GBP. Работает на Python 3.12 и Tkinter без сторонних пакетов.

## Запуск

В Windows откройте терминал в папке проекта:

```powershell
py -3.12 main.py
```

Если Python уже выбран в терминале или в PyCharm, запустите `python main.py`. Команда `python -m tkinter` открывает окно проверки Tkinter.

## Работа с курсами

- Введите положительную сумму, укажите пару и дату в формате ДД.ММ.ГГГГ. Рядом с результатом видны фактическая дата и источник курса. Сумму можно скопировать.
- График показывает стоимость одной единицы исходной валюты в целевой. Доступны периоды 7, 30, 90 дней и 1 год до выбранной даты. Наведите курсор на точку или выделите график клавишей Tab и используйте стрелки. На длинных периодах используется выборка дат. Изменение, минимум и максимум рассчитаны по показанным наблюдениям.
- Строка популярных пар переключает форму и график на EUR, USD, RON или GBP к MDL. Стрелка между валютами меняет направление расчёта. При сужении окна панели располагаются друг под другом.
- Если на дату нет котировки, конвертер ищет ближайший предыдущий курс в пределах 14 календарных дней и показывает причину подстановки. При отключении сети подходящий сохранённый курс можно применить через кнопку «Использовать кэш».

Курс последней онлайн-конвертации хранится в `data/cache/rates.json`. Отдельный файл `data/cache/history.json` сохраняет точки графика и позволяет открыть ранее загруженный период без сети. Оба файла создаются при работе программы. Источник котировок — [Национальный банк Молдовы](https://www.bnm.md/ru/content/obmennye-stavki).
