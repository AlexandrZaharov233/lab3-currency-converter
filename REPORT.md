# Лабораторная работа №3 по PSI

## 1. Источник данных

Выбран официальный XML Национального банка Молдовы. Он доступен без ключа и подходит для конвертера с базой MDL. Снимок содержит дату, код валюты, номинал и значение котировки. Цена одной единицы получается делением значения на номинал. Кросс-курс равен отношению цены исходной валюты к цене целевой. Расчёт выполняется с `Decimal`, сумма округляется до двух знаков. [Страница курсов BNM](https://www.bnm.md/ru/content/obmennye-stavki)

## 2. Инструменты и модели

В исходной сборке были документы Spec Kit 1.3.3, рабочий конвертер на Python 3.12 и Tkinter и набор unit-тестов. Исходный отчёт указывал ChatGPT для подготовки эталонной реализации и оставлял графу модели Antigravity пустой. Модель и этапы работы в Antigravity для исходной сборки не подтверждены. Расширение спецификации, переработка интерфейса и проверки этой версии выполнены в Codex.

## 3. Что заработало на первом запуске

Окно отобразило форму, график и карточки популярных пар. При проверке с подставленными XML-ответами загрузка истории выполнялась в фоне, переключатель периода менял диапазон, а выбор точки показывал дату и котировку. Все 27 тестов из исходной сборки прошли.

## 4. Ошибки и исправления

- Исходная обработка принимала ответ с пустым телом за ошибку формата. Теперь пустое тело запускает поиск предыдущей котировки, как и XML без валют. Неверный XML по-прежнему останавливает поиск.
- Дата из ответа теперь проверяется до расчёта. Снимок с датой после запроса пропускается. Котировки с бесконечностью и другими недопустимыми числами отклоняются.
- При первом повторном запуске проверка GUI обнаружила оставшийся таймер закрытого окна Tkinter. Таймеры теперь отменяются при закрытии. Повторная проверка прошла без ошибки.
- История сохраняется отдельно от кэша конвертации, чтобы просмотр прошлых периодов не заменял курс последнего расчёта.

## 5. Соответствие спецификации

| Требование | Проверка |
|---|---|
| FR-01, FR-07 | Запуск окна Tkinter, доступность интерфейса во время загрузки, широкая и узкая компоновки |
| FR-02, FR-03 | Валидация суммы и даты, обе стороны расчёта, учёт номинала, одинаковые валюты |
| FR-04 | Пустое тело и XML без котировок, предыдущая дата, уведомление в окне |
| FR-05, FR-06 | Сетевой сбой с подставленным ответом, повторный запуск окна, отказ и согласие на использование кэша |
| FR-08–FR-10 | Четыре периода, кросс-курс, уникальные даты точек, архив без сети, быстрые пары и копирование |

На Windows прошли 36 unit-тестов. Сценарии в окне проверены на контрольных XML-ответах BNM и при имитации сетевого сбоя. Прямой запрос к BNM из среды проверки завершился ошибкой DNS.

## 6. Git

Переданная сборка содержала файлы проекта без истории Git. Импорт и доработка подготовлены в трёх ветках: `001-currency-specs`, `002-currency-app` и `003-currency-tests-report`. Сначала зафиксирована спецификация, затем сервис и интерфейс, затем тесты и отчёт.
