# План реализации

## Технический контекст
Python 3.12, Windows, Tkinter. Стандартная библиотека: urllib.request, xml.etree.ElementTree, decimal, unittest. Внешних зависимостей у приложения нет. Spec Kit используется отдельно для документации.

## Проверка конституции
Интерфейс, сеть и чистые функции разделены. Тесты не обращаются к BNM. Кэш не коммитится. Сначала документы, затем реализация и тесты в отдельных PR.

## Структура
- main.py — точка запуска.
- app/core.py — ввод, даты, Decimal, нормализация XML и расчёт.
- app/rates.py — HTTP, выбор даты, локальный JSON и обработка ошибок.
- app/ui.py — форма Tkinter, фоновая загрузка, подтверждение кэша и быстрые пары.
- app/history.py — выбор дат, локальный архив BNM и расчёт исторических кросс-курсов.
- app/chart.py — отображение истории на Canvas, оси, выделение даты и подсказка.
- app/theme.py — палитра, типографика и состояния элементов Tkinter.
- tests/ — проверки unittest.

## Источник и хранение
HTTPS GET BNM с get_xml=1 и date=ДД.ММ.ГГГГ. Тайм-аут соединения/чтения 3 секунды, максимум 15 запросов для одного поиска. Каждый ответ ограничен 512 КиБ. Из ValCurs читать Date, из Valute — CharCode, Nominal и Value. Нормализовать как Value / Nominal. Расчёт: сумма × курс исходной / курс целевой. Кэш хранится в data/cache/rates.json относительно корня проекта и заменяется атомарно. Десятичные значения в JSON хранятся строками.

## Интерфейс
Конвертация и график выполняются в фоне. Результаты передаются в очередь, которую читает цикл Tkinter. Ошибку сети, пустые данные и неверный XML различает сервис. Подтверждение конвертации по кэшу находится в окне приложения.

Для истории переиспользуется XML-клиент BNM. Даты выбираются с шагом, зависящим от длины периода. Дата точки берётся из XML. Сохранённые снимки используются повторно и позволяют показать историю без сети. Архив хранится отдельно от последнего курса для конвертации. При смене даты или периода устаревшая загрузка отменяется, а работающий запрос проверяется на актуальность перед отрисовкой.

Форма и график стоят рядом в широком окне и друг под другом в узком. На графике показываются точные значения выбранной точки, изменение и диапазон по видимым наблюдениям. Строка популярных пар использует те же снимки BNM.

## Проверка
На Windows выполнить python -m tkinter и python main.py. Unit-тесты: python -m unittest discover -s tests -v. Реальные сценарии запуска и отключения сети записать в REPORT.md.
