# Анализ согласованности перед реализацией

| Требование | План | Задачи |
|---|---|---|
| FR-01, FR-07 | GUI и фоновая загрузка | T005, T009 |
| FR-02 | Валидация | T001, T007 |
| FR-03 | XML и Decimal | T002, T006, T007 |
| FR-04 | Поиск курса | T003, T008 |
| FR-05, FR-06 | Обработка ошибок и кэш | T004, T005, T008, T009 |
| FR-08, FR-09 | Архив, фоновые запросы, график | T011, T012, T013 |
| FR-10 | Компоновка и быстрые действия | T012 |

Проверены три неоднозначности: пустой ответ запускает поиск, повреждённый ответ прекращает его; кэш используется после согласия; при одинаковых валютах дата курса не применяется. Проверка GUI и источника по сети остаётся этапом приёмки.

График использует ту же пару и выбранную дату, что и форма. Архив графика хранится отдельно, чтобы просмотр истории не менял сохранённый курс последней конвертации. Диапазон и изменение считаются по показанным точкам.
